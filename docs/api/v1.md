# HARIS API v1

Dokumentasi ini mencakup endpoint API yang aktif di `routes/modules/api.v1.php`.

Base URL lokal:

```text
http://localhost:8000/api/v1
```

## Autentikasi

API memakai Laravel Sanctum token. Ambil token dari endpoint login, lalu kirim di header:

```http
Authorization: Bearer <access_token>
Accept: application/json
Content-Type: application/json
```

Format respons standar:

```json
{
  "success": true,
  "message": "Request completed successfully",
  "data": {}
}
```

Respons validasi Laravel memakai status `422` dan field `errors`. Endpoint yang membutuhkan role tetap memakai role aplikasi: `Administrator`, `Payroll Officer`, `Payroll Approver`, `Finance Approver`, dan `Employee`.

## Auth

| Method | Endpoint | Akses | Keterangan |
| --- | --- | --- | --- |
| POST | `/auth/login` | publik | Membuat Sanctum token. |
| GET | `/auth/me` | token | Mengambil profil user dari token aktif. |

Login payload:

```json

  "password": "ChangeMe123!",
  "device_name": "postman"

```

Akses CRUD: `Administrator`. Akses process: role payroll.

| Method | Endpoint | Query/Payload |
| --- | --- | --- |
| GET | `/payroll-periods` | pagination default |
| POST | `/payroll-periods` | create payload |

| POST | `/payroll-periods/{payrollPeriod}/process` | memproses payroll run |

Create/update payload:

```json
{
  "payroll_group_id": 1,
  "period_name": "April 2026",
  "start_date": "2026-04-01",

  "pay_date": "2026-04-25",
```

## Postman

Koleksi Postman tersedia di:

```text
docs/api/HARIS_API_v1.postman_collection.json
docs/api/HARIS_API_v1.postman_environment.json
```

Cara pakai:

1. Import collection dan environment.
2. Aktifkan environment `HARIS API v1 Local`.
3. Jalankan `Auth / Login`.
4. Token akan otomatis disimpan ke variable `token`.
5. Jalankan endpoint lain dengan header Bearer token dari collection auth.
